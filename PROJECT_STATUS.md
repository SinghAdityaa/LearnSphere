# Project status

## Working in this ZIP

- React/Vite responsive frontend
- Express REST API
- MongoDB/Mongoose models
- Google identity verification flow
- Development demo login
- HTTP-only JWT authentication cookie
- Student/admin roles and protected routes
- Course catalog, filters and search
- Course details and syllabus
- Enrollment
- Favorites
- Lesson player and persistent completion progress
- Student dashboard
- MCQ assessments scored by the backend
- Quiz attempt history storage
- Certificate issuance and PDF download
- Admin analytics/counts
- Admin course create, publish/unpublish and delete
- Admin quiz upsert API
- Seed script with demo courses and quizzes
- Docker Compose MongoDB
- Security middleware, rate limiting and input validation
- Responsive design
- Starter privacy/terms pages and favicon

- Cloudinary upload UI
- Rich visual module/lesson editor in admin
- Student notes and whiteboard
- Notifications
- Instructor accounts
- Real student review system
- Paid courses and payments
- Discussion forums
